# dsh-subagent-sidebar

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![npm version](https://img.shields.io/npm/v/@exagone313/dsh-subagent-sidebar)](https://www.npmjs.com/package/@exagone313/dsh-subagent-sidebar)
[![GitHub release](https://img.shields.io/github/v/release/Exagone313/dsh-subagent-sidebar)](https://github.com/Exagone313/dsh-subagent-sidebar/releases)

English | [中文](README.zh.md)

A right-sidebar tab for [DeepSeek Harness](https://deepseek.com/harness) (`dsh`)
that lists subagents and opens them in one click. dsh's built-in subagent UI is
not convenient, so this plugin adds an easier sidebar for it.

## Install

```sh
dsh plugin --profile web add @exagone313/dsh-subagent-sidebar
```

Restart dsh afterwards.

## Remove

```sh
dsh plugin --profile web remove @exagone313/dsh-subagent-sidebar
```

Restart dsh afterwards.
