# dsh-subagent-sidebar

[![npm version](https://img.shields.io/npm/v/@exagone313/dsh-subagent-sidebar)](https://www.npmjs.com/package/@exagone313/dsh-subagent-sidebar)

[English](README.md) | 中文

用于 [DeepSeek Harness](https://deepseek.com/harness)（`dsh`）右侧边栏的标签页，
列出子智能体，一键打开。dsh 自带的子智能体界面不太好用，因此本插件在侧边栏
提供一个更易用的界面。

## 安装

```sh
dsh plugin --profile web add @exagone313/dsh-subagent-sidebar
```

随后重启 dsh。

## 移除

```sh
dsh plugin --profile web remove @exagone313/dsh-subagent-sidebar
```

随后重启 dsh。
